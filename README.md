# Dog Breed Prediction 🐶

A Streamlit web application that predicts dog breed from an uploaded image using a trained deep learning model.

## Features
- Upload dog image
- CNN model prediction
- Simple web interface

## Tech Stack
- Python
- Streamlit
- TensorFlow / Keras
- OpenCV
- NumPy

## How to Run

```bash
pip install -r requirements.txt
streamlit run main_app.py
